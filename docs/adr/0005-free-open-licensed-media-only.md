# Only free, openly licensed art and sound

All art and sound in the game must be free and either public domain or under an open licence that allows it to be stored in a public GitHub repository. Nothing is bought, even where a paid model would look better. The game is likely to stay for personal use, but we don't want to have to worry about what's in the repository. We accept that near-future spacecraft will be the weakest visuals as a result.

## Consequences

- Check each file's licence when adding it, and record its source and licence alongside it. Licences that forbid redistribution or modification don't qualify.
- NASA media is generally free to use, but NASA's logos and insignia have their own restrictions, so leave them out.
